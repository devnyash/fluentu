How it works

From one language to many. Without the mess.

Connect your docs, let Fluentu learn your project, then ship translations that actually sound like your product.

01

Connect your docs

Link your Git repo, Notion workspace, or markdown files. Fluentu reads your documentation structure and builds a project glossary.

02

AI translates with context

Fluentu translates using your terminology, code examples, and tone of voice. Every translation is checked against your style guide.

03

Ship in every language

Publish translated docs alongside your source. When you update the source, Fluentu flags what needs re-translation.

FAQ

Common questions.

Does Fluentu replace human translators?
No. It handles the first pass — fast, consistent, context-aware. Human translators review and refine. You get speed without sacrificing quality.
What languages do you support?
We launch with English, Spanish, German, French, Japanese, Korean, and Portuguese. More languages are added based on customer demand.
How do you handle code blocks?
Code is never translated. Fluentu identifies code blocks, inline code, and API references, and leaves them untouched. Comments inside code are translated separately.
Where is my data stored?
Your docs and glossaries stay in your environment. Fluentu processes translations without storing your content permanently. Self-hosted deployment is on the roadmap.
Can I try it before committing?
Yes. We offer a free trial with 1,000 words so you can see the quality before you pay. No credit card required.
